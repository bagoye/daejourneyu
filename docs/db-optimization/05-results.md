## 운영 실습실 (ops-lab, 상세는 06)

| 항목 | 결과 | 검증 |
|---|---|---|
| PITR(사고 트랜잭션 직전 복구) | WHERE 없는 UPDATE + CASCADE 삭제를 되돌림, **6/6 완전 일치**, RTO 3.3~5.6초 | 정합성 스냅샷 diff 0 |
| 시각 기반 PITR의 함정 | 1회 실패 → 원인: 컨테이너 시계가 약 27초마다 3.7초 역행 | 시계 관측(90초 4회 역행) |
| 시계와 무관한 복구 | pg_waldump로 사고 xid 특정 → recovery_target_xid | 연속 5회 성공 |
| RTO와 WAL 양 | 31MB→3.1초, 474MB→8.3초, 1.5GB→14.5초, 3GB→37.8초 | 베이스 백업 주기 근거 |
| WAL 보관 정책 | 무정리 5.6GB → 최근 2개 백업 기준 정리로 약 150~180MB 유지 | 정리 후에도 복구 성공 |
