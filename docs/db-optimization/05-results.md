## 1차: 정합성·동시성 (완료, 상세는 02)
| 항목 | 개선 전 | 개선 후 | 검증 |
|---|---|---|---|
| DB 오류 시 서버 동작 | 무응답 + Unhandled Rejection | 상태 코드별 JSON 응답 | 단위 테스트 |
| 동시 중복 담기 10건 | 8~9건 409 | 전부 200, 사본 1개 | 통합 테스트 20회 |
| 동시 취소 10건 | 9건 404 | 전부 200 | 통합 테스트 20회 |
| 교착(취소↔코스 삭제, PATCH↔DELETE) | 재현됨 | 0회 | PG 서버 로그 |
| 동시 코스 PATCH 8건 | 7건 실패 | 전부 200, 동선 혼합 없음 | 통합 테스트 20회 |
| saves 드리프트(CASCADE·시드) | 발생 | 0 (트리거 + CHECK) | 통합 테스트 + 마이그레이션 검증 |
| 커서 글 삭제 시 목록 | 6개 중 2개만 받고 종료 | 끝까지 이어 받음 | 통합 테스트 |
| 커서 글 담긴 수 변경 시 | 이미 본 글 중복 | 경계 고정(값 기반 커서) | 통합 테스트 |
| 마이탭 후기 응답 | 전 사용자 후기(12건 중 내 것 3건) | 내 후기만(3건) | 통합 테스트 |
| 장소 후기 | 전체 한 번에(사진 포함) | 10개씩 + 더보기 | 프론트 훅 테스트 |
